# CGW

CGW（Cursor Gateway）是 Cursor 的本机网关客户端：默认用你电脑上已经登录的 Cursor 账号工作，也可以按需切到自己的服务器线路。

没登录官方管理后台也能用。本地线路不需要 Token、不需要远端账号；只有要用团队号池、计费或远程转发时，才接到网关服务器。

这个仓库只放安装包和发行目录，不含源码。

## 它做什么

Cursor 的请求会经过本机常驻服务。你可以：

- 继续用本机 Cursor 账号（默认）
- 在多个本机账号之间切换、看用量
- 需要时改走自己部署的网关

桌面管理工具只负责安装、状态和账号，**不承载流量**。关掉管理窗口，本地服务仍在转发。

## 要装哪些

从 [最新 Release](https://github.com/FungZachary/cgw-releases/releases/latest) 下载：

| 文件 | 是什么 |
| --- | --- |
| `cgw-agent.vsix` | Cursor 插件。装进编辑器后负责线路切换、拉起本地服务 |
| `cgw-agent-<平台>` | 本地服务。常驻本机，转发流量、管理号池 |
| `cgw-desktop-<平台>` | 桌面管理工具。安装插件和服务、查看状态 |

平台名：`win32-x64`、`linux-x64`、`darwin-x64`、`darwin-arm64`。

网关服务端（`cgw-server`）不在这里发布，需要自己部署。

## 访问 GitHub 不通时

在管理工具设置或插件设置里填写「发行源代理」，例如 `http://127.0.0.1:7890`。只影响下载安装包和发行目录，连自己的网关不受影响。留空则跟随系统代理，再没有就直连。
